# JavaScript Study Notes

These are my personal study notes, written while learning and working with JavaScript. They gather the core language ideas and browser APIs I want to understand, practise, and revisit in one place.

Each chapter explains a topic in beginner-friendly language, then builds it up with practical code examples and checks for understanding. Most language examples can be run in a browser console or in a modern JavaScript runtime. Browser chapters say when a page or browser API is needed.

## How to use these notes

Start with the first chapter and move through the core topics in order. Run the examples, change their inputs, and write a small variation before moving on. The final chapters collect the code samples and answer the review questions from the full set.

## Core chapters

1. [Start with JavaScript](./chapters/01-start-with-javascript.md) - What JavaScript is, where it runs, and how to run a first script.
2. [Values, variables, and types](./chapters/02-values-variables-and-types.md) - Declarations, primitive values, references, conversions, and scope basics.
3. [Operators and control flow](./chapters/03-operators-and-control-flow.md) - Expressions, comparisons, conditions, loops, and readable branching.
4. [Functions and closures](./chapters/04-functions-and-closures.md) - Function declarations, parameters, return values, callbacks, and lexical scope.
5. [Arrays and iteration](./chapters/05-arrays-and-iteration.md) - Creating, reading, transforming, and iterating over ordered data.
6. [Objects and properties](./chapters/06-objects-and-properties.md) - Object literals, property access, copying, destructuring, and safe updates.
7. [Prototypes and classes](./chapters/07-prototypes-and-classes.md) - Prototype delegation, class syntax, inheritance, and composition.
8. [Built-in collections](./chapters/08-built-in-collections.md) - Map, Set, weak collections, and choosing the right data structure.
9. [Strings, numbers, dates, and regular expressions](./chapters/09-strings-numbers-dates-and-regex.md) - Common built-ins for text, numeric work, dates, formatting, and pattern matching.
10. [Errors and debugging](./chapters/10-errors-and-debugging.md) - Throwing and handling errors, validation, browser tools, and reliable diagnostics.
11. [The DOM and page updates](./chapters/11-dom-and-page-updates.md) - Finding elements, changing content, creating nodes, and keeping updates accessible.
12. [Events and forms](./chapters/12-events-and-forms.md) - Event listeners, event flow, form data, validation, and user input.
13. [Asynchronous JavaScript](./chapters/13-asynchronous-javascript.md) - The event loop, promises, async functions, timers, and cancellation.
14. [JavaScript modules](./chapters/14-javascript-modules.md) - ES module files, named and default exports, imports, and dynamic loading.
15. [HTTP requests with Fetch](./chapters/15-http-requests-with-fetch.md) - Requests, JSON responses, status handling, cancellation, and practical error paths.
16. [Browser storage and safe patterns](./chapters/16-browser-storage-and-safe-patterns.md) - Web storage, persistence limits, safe rendering, and browser security basics.
